# Part 2: Continuous Delivery

## Continuous Deployment Risk:
If we use Continuous Deployment, a wrong change (like removing a line in `index.html`) could pass tests but still break the page for users. Visitors might see errors or missing content immediately.

## Continuous Deployment Benefit:  
Every change goes live faster. We get quick feedback and updates without waiting for manual approval, which saves time and makes the site always up to date.
